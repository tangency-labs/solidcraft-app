Bring your designs to the new address

The SolidCraft web app moved from docs.solidcraft.io/app/ to app.solidcraft.io. A browser keeps what you save separately for each address, so designs you saved at the old one don't appear here until you copy them. The originals stay at the old address: nothing there is changed or deleted.

Done

    Open SolidCraft. If it's already open in another tab, reload that tab to see the designs.

    Copy them by hand

    1. Open the page at the old address in this browser.
    2. Save each design as a file with its button. The old app can do the same: File > Files in this browser…, then Download beside each design.
    3. In SolidCraft, open each file with File > Open.

    If a design won't open

    The old address ran the newest development builds until November 3, 2026, so a design saved there may be newer than this release can read. It's still safe: try it in the release candidate, which keeps its own storage too. Save the design as a file from the page at the old address and open that file in the release candidate.

    Designs you saved to a file on your computer were never in the browser's storage. Open them here with File > Open.
